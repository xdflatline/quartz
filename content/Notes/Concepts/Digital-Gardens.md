# Digital Gardens

> [!quote] "A digital garden is a collection of evolving ideas that aren't strictly organized by publication date." — Maggie Appleton

## Definition

A **digital garden** is a personal knowledge base published on the web that:
- Grows organically over time (not chronological like a blog)
- Shows work-in-progress thinking (not just polished essays)
- Embraces imperfection and revision
- Uses bidirectional links to form a knowledge graph

## Core Principles

| Principle | Description |
|-----------|-------------|
| **Non-linear** | Navigate via links, not chronology |
| **Incremental** | Publish early, refine often |
| **Interconnected** | Bidirectional links create context |
| **Public by default** | Learn in public, invite serendipity |

## Garden vs. Blog

| Aspect | Blog | Digital Garden |
|--------|------|----------------|
| Organization | Reverse chronological | Topical / graph-based |
| Content State | Polished, final | Evolving, WIP |
| Navigation | Categories, tags | Wikilinks, backlinks, graph |
| Goal | Broadcast | Cultivate understanding |

## Tools & Platforms

- **Quartz** — Static site, Obsidian-compatible, GitHub Pages
- **Obsidian Publish** — Hosted, paid, seamless Obsidian sync
- **Notion + Super** — Visual, database-driven
- **TiddlyWiki** — Single-file, portable, self-hosted
