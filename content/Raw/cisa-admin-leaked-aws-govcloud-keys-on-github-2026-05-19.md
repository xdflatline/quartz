CISA Admin Leaked AWS GovCloud Keys on Github &#8211; Krebs on Security --> Advertisement Advertisement --> Skip to content Home About the Author Advertising/Speaking CISA Admin Leaked AWS GovCloud Keys on Github May 18, 2026 50 Comments Until this past weekend, a contractor for the Cybersecurity &amp; Infrastructure Security Agency (CISA) maintained a public GitHub repository that exposed credentials to several highly privileged AWS GovCloud accounts and a large number of internal CISA systems. Security experts said the public archive included files detailing how CISA builds, tests and deploys software internally, and that it represents one of the most egregious government data leaks in recent history. On May 15, KrebsOnSecurity heard from Guillaume Valadon , a researcher with the security firm GitGuardian . Valadon&#8217;s company constantly scans public code repositories at GitHub and elsewhere for exposed secrets, automatically alerting the offending accounts of any apparent sensitive data exposures. Valadon said he reached out because the owner in this case wasn&#8217;t responding and the information exposed was highly sensitive. A redacted screenshot of the now-defunct &#8220;Private CISA&#8221; repository maintained by a CISA contractor. The GitHub repository that Valadon flagged was named &#8220; Private-CISA ,&#8221; and it harbored a vast number of internal CISA/DHS credentials and files, including cloud keys, tokens, plaintext passwords, logs and other sensitive CISA assets. Valadon said the exposed CISA credentials represent a textbook example of poor security hygiene, noting that the commit logs in the offending GitHub account show that the CISA administrator disabled the default setting in GitHub that blocks users from publishing SSH keys or other secrets in public code repositories. &#8220;Passwords stored in plain text in a csv, backups in git, explicit commands to disable GitHub secrets detection feature,&#8221; Valadon wrote in an email. &#8220;I honestly believed that it was all fake before analyzing the content deeper. This is indeed the worst leak that I&#8217;ve witnessed in my career. It is obviously an individual’s mistake, but I believe that it might reveal internal practices.&#8221; One of the exposed files, titled &#8220;importantAWStokens,&#8221; included the administrative credentials to three Amazon AWS GovCloud servers. Another file exposed in their public GitHub repository &#8212; &#8220;AWS-Workspace-Firefox-Passwords.csv&#8221; &#8212; listed plaintext usernames and passwords for dozens of internal CISA systems. According to Caturegli, those systems included one called &#8220;LZ-DSO,&#8221; which appears short for &#8220;Landing Zone DevSecOps,&#8221; the agency&#8217;s secure code development environment. Philippe Caturegli , founder of the security consultancy Seralys , said he tested the AWS keys only to see whether they were still valid and to determine which internal systems the exposed accounts could access. Caturegli said the GitHub account that exposed the CISA secrets exhibits a pattern consistent with an individual operator using the repository as a working scratchpad or synchronization mechanism rather than a curated project repository. &#8220;The use of both a CISA-associated email address and a personal email address suggests the repository may have been used across differently configured environments,&#8221; Caturegli observed. &#8220;The available Git metadata alone does not prove which endpoint or device was used.&#8221; The Private CISA GitHub repo exposed dozens of plaintext credentials for important CISA GovCloud resources. Caturegli said he validated that the exposed credentials could authenticate to three AWS GovCloud accounts at a high privilege level. He said the archive also includes plain text credentials to CISA&#8217;s internal &#8220;artifactory&#8221; &#8212; essentially a repository of all the code packages they are using to build software &#8212; and that this would represent a juicy target for malicious attackers looking for ways to maintain a persistent foothold in CISA systems. &#8220;That would be a prime place to move laterally,&#8221; he said. &#8220;Backdoor in some software packages, and every time they build something new they deploy your backdoor left and right.&#8221; In response to questions, a spokesperson for CISA said the agency is aware of the reported exposure and is continuing to investigate the situation. &#8220;Currently, there is no indication that any sensitive data was compromised as a result of this incident,&#8221; the CISA spokesperson wrote. &#8220;While we hold our team members to the highest standards of integrity and operational awareness, we are working to ensure additional safeguards are implemented to prevent future occurrences.&#8221; A review of the GitHub account and its exposed passwords show the &#8220;Private CISA&#8221; repository was maintained by an employee of Nightwing , a government contractor based
