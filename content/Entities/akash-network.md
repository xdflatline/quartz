# Akash Network

**Akash Network** is a decentralized cloud computing marketplace built on the Cosmos SDK. It operates as an open, permissionless network where independent providers compete to offer high-performance compute and GPU resources.

## Core Capabilities

1. **Decentralized Marketplace**: Instead of relying on centralized cloud providers like AWS, GCP, or Azure, users deploy workloads to a global network of independent providers spanning 85+ countries.
2. **Reverse Auction Model**: Users define their application's resource requirements (CPU, RAM, storage, GPU) in a declarative YAML file. Providers then bid to host the workload, and users select the optimal offer based on price, location, and reputation.
3. **Significant Cost Savings**: Driven by the competitive bidding process and utilization of underused data center capacity, workloads on Akash can be hosted at up to 85% lower cost compared to traditional cloud platforms.
4. **Censorship Resistance**: Due to its decentralized nature, no single entity has the authority to arbitrarily shut down an application, making it highly resilient.
5. **Universal Workload Support**: Akash can host virtually any application that can run in a Docker container, including web applications, databases, and AI/ML workloads requiring high-end GPUs.
6. **Flexible Payment**: Operations are paid per block using tokens like AKT or USDC, with options for permissionless, non-KYC access.

## Workflow

1. **Deploy**: Define resources in a YAML file (SDL - Stack Definition Language).
2. **Bid**: Providers submit competing bids to host the application.
3. **Choose**: The user selects a provider bid.
4. **Run**: The application runs, with payments streaming continuously per block.
