# Martin Fowler

**Source:** [martinfowler.com](https://martinfowler.com/)
**Category:** Software Author / Consultant / ThoughtWorks Chief Scientist

## Overview

Martin Fowler is the chief scientist at ThoughtWorks and author of the canonical practitioner site [martinfowler.com](https://martinfowler.com/), which hosts the first microservices article (with James Lewis), a regular bliki on software architecture and design, and the influential book *Patterns of Enterprise Application Architecture*.

## Mentions in the Sam Newman interview

- **Co-author of the first microservices paper** with James Lewis, ~2014, on Fowler's website.
- **Newman's mentor for the first book** — supported Newman through writing *Building Microservices* during his ThoughtWorks tenure.
- **"Programming is not typing"** — the line Fowler gave Newman that re-frames manager pushback on pair programming. If the client thinks programming is typing, the deeper issue is what they think software development *is* — not whether to pair. This framing extends naturally to AI: if management thinks programming is code-generation, the same deeper question applies.
