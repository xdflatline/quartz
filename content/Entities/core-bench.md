# CORE-Bench

**Source:** Siegel et al., "CORE-Bench: Fostering the Credibility of Published Research Through a Computational Reproducibility Agent Benchmark," TMLR 2024.

## Overview

Evaluate computational reproducibility of published research. 270 tasks based on 90 scientific papers across CS, social science, and medicine. Tasks involve reproducing results from provided code and data.

## Scale

- 270 tasks
- 90 scientific papers
- CS, social science, medicine
- Multiple difficulty levels
- Language-only and vision-language tasks

## SOTA

Best reported agent at the time (GPT-4o and GPT-4o-mini) achieved only 21% accuracy on the hardest task.
