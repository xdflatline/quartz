## Overview

[uv](https://github.com/astral-sh/uv) is an ultra-fast Python package installer and resolver written in Rust by Astral, intended as a drop-in replacement for pip, poetry, and virtualenv.

## Critique on UX

- While execution speed is unparalleled, developers have noted that the command line structure and project/lockfile workflows have evolved too rapidly, resulting in complex and disjointed package management user experiences.
