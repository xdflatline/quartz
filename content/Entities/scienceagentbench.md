# ScienceAgentBench

**Source:** Chen et al., "ScienceAgentBench: Toward Rigorous Assessment of Language Agents for Data-Driven Scientific Discovery," ICLR 2025.

## Overview

102 tasks from 44 peer-reviewed publications across four disciplines: math, chemistry, biology, geography. Tasks cover the basic data-science workflow: data processing, model development, data analysis, and information visualization.

## Scale

- 102 tasks
- 44 peer-reviewed publications
- 4 disciplines: math, chemistry, biology, geography

## Why It Matters

Grounds LLM evaluation in **real published scientific tasks** rather than synthetic or simplified problems. A task that a real paper needed done is a task that, if automated, would be useful.
