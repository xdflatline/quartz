# nrf52840 MCU

The **nrf52840** is a Nordic Semiconductor 32-bit ARM Cortex-M4 BLE SoC. It is the **main controller** on the Corne and Sofle "Eyelash" keyboards documented in the [[Raw/manuals-plus-corne-mechanical-split-keyboard-2026-08-20]] manual. The main control core board on these keyboards is labelled "52840micro".

## Why nrf52840 for split keyboards

Three properties matter:

- **Built-in BLE radio.** Powers both the host-facing Bluetooth (4–5 profile store) and the inter-half pairing link. The manual documents normal inter-half range as 0.6–0.8 meters — consistent with the chip's low-power BLE radio tuned for very short range.
- **USB device controller.** Powers the wired USB-keyboard mode, charging input, and — critically — the **USB-mass-storage bootloader** that the Corne / Sofle keyboards rely on for drag-and-drop firmware updates.
- **Sufficient flash and RAM** for ZMK firmware plus the multi-profile Bluetooth host store and the persistent settings area that holds left/right pairing state across firmware updates.

## Roles on the Corne/Sofle

- **Main half (left)** runs ZMK, owns the BLE radio that talks to the host, holds the 4–5 Bluetooth profile store, and exposes the USB device.
- **Right half** also runs ZMK on its own nrf52840 but uses the radio only for the inter-half link.

## Reset behaviour

- Single press of the reset switch → restart.
- **Double press within 0.5 seconds (with USB plugged in)** → bootloader (USB mass-storage enumeration). Blue LED breathes to indicate the state.
- `&bootloader` ZMK keycode provides a software path to the same state.
