# Squirrel (Auto-maintaining Documentation)

**Source:** HN Discussion (https://news.ycombinator.com/item?id=46742800)
**Category:** Tool / Open Source Project
**Repository:** https://github.com/hakoniwaa/Squirrel

---

## Overview

OSS experiment for **auto-maintaining project documentation** (e.g., `CLAUDE.md`, `agents.md`) based on agent activity. Addresses the problem of stale manual documentation.

---

## Problem Solved

- Manual `CLAUDE.md`/`agents.md` upkeep is neglected
- Documentation drifts from actual project state
- Agents operate on outdated constraints

---

## Approach

- Monitor agent activity (code changes, decisions, patterns)
- Auto-generate/update documentation files
- Keep docs in sync with actual project evolution

---

## Status

- Early experiment / proof of concept
- Open source: https://github.com/hakoniwaa/Squirrel
- Referenced in HN thread as promising direction
