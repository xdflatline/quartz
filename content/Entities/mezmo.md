## Overview

Mezmo is the company that builds and maintains the [AURA](https://github.com/mezmo/aura) open-source agentic-harness project. Mezmo historically positioned as a log-observability platform (originally LogDNA, rebranded), and the AURA project is the company's move into AI-driven SRE workflows. The AURA repo lives under the `mezmo/` GitHub org, the `model_owner = "mezmo"` field in agent configs is used to override the `owned_by` field exposed via `/v1/models`, and the AURA Slack community is hosted on the `mezmo.com` domain.

## Key Details

- **AURA repo org:** `mezmo` (https://github.com/mezmo)
- **AURA license:** Apache 2.0
- **Community channel:** `mezmo.com/r/slack-aura`
- **Product strategy:** self-hosted, open-core agentic harness targeted at SRE/operations use cases
