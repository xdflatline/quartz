# dots-hyprland (Illogical-Impulse)

**Source:** Documentation bundle ([[Raw/quickshell-org-docs-bundle-2026-08-31]])

## Overview

Illogical-Impulse (commonly referred to by its repository name `dots-hyprland`) is the second flagship Hyprland + Quickshell configuration on quickshell.org's showcase table. It pairs an opinionated Hyprland rice with a Quickshell shell config that supplies the bar, widgets, and lockscreen, making it a turnkey starting point for users who want a configured shell without writing QML themselves.

## Key Details

### Role in the Quickshell ecosystem

- Listed on quickshell.org home and about pages as the flagship showcase alongside [[Entities/caelestia]]
- Quickshell config lives in the same monorepo as the Hyprland config and supporting scripts (in contrast to setups where the shell config is in a separate repo)
- Often referenced as a reference for end-user QML patterns (custom widgets, animations, IPC consumers)
