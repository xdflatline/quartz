# Caelestia

**Source:** Documentation bundle ([[Raw/quickshell-org-docs-bundle-2026-08-31]])
**Category:** Project / Configuration
**Repository:** https://github.com/caelestia-dots/shell
**Author:** Soramane (caelestia-dots)
**Built on:** Hyprland + [[Entities/quickshell]]

## Overview

Caelestia is a Hyprland-based Linux desktop configuration that uses Quickshell as its panel, widgets, and lockscreen layer. It is the first config listed on quickshell.org's showcase table and the canonical "I want a preconfigured desktop" recommendation from the Quickshell project's own about page. The repository hosts the Quickshell-side shell configuration; the broader rice (Hyprland config, theming, scripts) lives in the surrounding `caelestia-dots` organization.

## Key Details

### Role in the Quickshell ecosystem

- Listed on quickshell.org home and about pages as the flagship showcase alongside [[Entities/dots-hyprland-illogical-impulse]]
- Repository name `caelestia-dots/shell` suggests the Quickshell-side shell config is one of multiple "dot" repos in the caelestia-dots org
- Serves as the reference implementation that downstream users fork or pattern-match when they want a working QML desktop shell without authoring it from scratch
