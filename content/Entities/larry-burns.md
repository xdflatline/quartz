# Larry Burns

**Category:** Person

---

## Overview

Larry Burns is a commenter on Joe Reis's *Mixed Model Arts Manifesto* (Aug 25, 2026) whose response has been independently notable in the wiki's research synthesis. Burns endorses Reis's framing and adds a sharp operational demand: in the Agentic Era, **semantic data must exist independently of both the database schema and the application code**, so it can be consumed mechanically by AI agents. He argues that the right architecture is for a modeling tool to generate both the persistence schema **and** the ontology document from a single modeling exercise — turning semantics into a first-class, machine-consumable deliverable rather than documentation.

The contribution operationalizes MMA Belief 5 (semantics as the universal interface): Reis's belief is a framing claim, Burns's comment is the engineering requirement that would make the belief real.

## Key Details

- **Comment date:** 2026-08-25
- **Comment on:** Joe Reis, *The Mixed Model Arts Manifesto*, Practical Data Modeling
- **Liked by Joe Reis** (Reis endorsed the comment)

### The argument in Burns's own words

> "Now, in the age of Agentic AI, semantic data (or metadata as we might call it) must exist independently of both the database schema and the application code, so that it can be consumed mechanically. […] If our modeling tools can be somehow enabled to accommodate both data requirements and data meaning, if our tools could generate both persistence schemas and ontology documents, then a single modeling exercise could generate all the artifacts needed to create data that can be consumed by both human and AI agents."

The two structural requirements that follow:

1. **Semantic data is physically decoupled from schema and code.** Not embedded in column comments; not buried in application logic.
2. **Modeling tools generate both persistence and ontology.** Single exercise, two artifacts, machine-consumable.
