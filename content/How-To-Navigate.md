# How to Navigate This Garden

## Primary Navigation

### Top Bar (Always Visible)
- **Site Title** → Home page
- **Search** (`Ctrl/Cmd + K`) — Full-text search across all notes
- **Graph** — Interactive knowledge graph visualization
- **Dark Mode Toggle** — Switch light/dark theme

### Left Sidebar (Explorer)
- **Folder Tree** — Hierarchical view of all notes
- **Tags** — Click any tag to see tagged notes
- **Backlinks** — See what links to current note

### Right Sidebar (Context)
- **Table of Contents** — Headings in current note
- **Backlinks** — Notes linking to current page
- **Graph Local** — Mini graph of connected notes

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open search |
| `g` then `h` | Go to home |
| `g` then `g` | Open graph view |
| `?` | Show all shortcuts |
| `Esc` | Close modals/panels |

## Wikilinks & Navigation

### Wikilinks Syntax
```markdown
[[Note Title]]                    # Link to note
[[Note Title#heading]]            # Link to heading
[[Note Title\|Custom Text]]       # Link with alias
```

### Special Links
- **Tags**: Click any `#tag` to see all notes with that tag
- **Folders**: Click folder names in explorer to see folder page
- **Graph Nodes**: Click any node in graph to navigate

## Mobile Navigation

- **Hamburger Menu** — Opens sidebar drawer
- **Bottom Toolbar** — Search, Graph, Dark Mode
- **Swipe** — Close sidebars, navigate history

## Pro Tips

1. **Graph View**: Use filters (tags, folders) to focus exploration
2. **Search**: Supports fuzzy matching — type partial words
3. **Backlinks**: Essential for discovering connections you didn't make explicit
4. **Folder Pages**: Auto-generated index of folder contents with summaries
