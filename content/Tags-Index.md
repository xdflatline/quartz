## How to Use Tags

1. **Click any tag** in a note → See all notes with that tag
2. **Visit tag page** → Auto-generated page with all tagged notes
3. **Combine tags** in search → `tag:quartz tag:project`
4. **Tag hierarchy** → Tags can be nested (e.g., `#project/active`)
